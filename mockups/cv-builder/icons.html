Icon packs for the CV

Same 8 icons in each pack: email, phone, birth date, licence, location, languages, website, LinkedIn. The last column shows them at the real CV size, in the CV's grey. Packs without a LinkedIn icon use the one from Simple Icons.

Current: Tabler (outline). To use another pack I'd install it (or copy just these 8 SVG files into the project) and change one list in icons.ts; the preview and the PDF both read from it. Filled packs (Font Awesome, Phosphor fill) look heavier on paper; thin outline packs look lighter.
